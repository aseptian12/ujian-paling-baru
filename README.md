# Ujian Online

Frontend statis (HTML/CSS/JS) untuk GitHub Pages. Backend: Google Apps Script (`Kode.gs`, diberikan terpisah).
1. Isi `GAS_URL` di `js/config.js`.
2. Push folder ini ke repository GitHub Public, aktifkan Pages (branch `main`, root).
Lihat `PANDUAN-INSTALASI.md` untuk langkah lengkap.
